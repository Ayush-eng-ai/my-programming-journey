# My Programming Journey

A structured collection of my programming learning and practice across HTML5, CSS3, Java, JavaScript, SQL, and Python.

This repository is a personal learning archive documenting my progress through multiple technologies, from beginner fundamentals to problem-solving exercises, daily practice files, and project work.

## Overview

The repository is organized by technology and learning stage, making it easy to revisit notes, scripts, assignments, and small practice projects.

## Learning tracks included

- HTML5 and CSS3
- JavaScript fundamentals and chapter-based practice
- Java programming exercises and daily learning folders
- SQL learning and database practice
- Python learning, data/statistics learning, and coding challenges
- Problem-solving and solution notes
